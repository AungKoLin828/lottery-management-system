# Lottery Management System

## Technology

Frontend:

- React 19
- TypeScript
- Vite
- Tailwind CSS

Backend:

- Netlify Functions
- Node.js

Database:

- MongoDB Atlas

## Run Project

Install:

npm install

Start:

npm run dev

npm install -g netlify-cli

netlify dev

## Deployment

Deploy using Netlify.
